# About these notes

I put this together from my setup notes, terminal output, and screenshots. It's a record of how I built and moved the servers, rather than an installer that configures everything automatically.

Some command blocks are the original commands; others group the checks into a sequence that's easier to follow. I've replaced addresses and temporary process IDs with placeholders. Where something was only planned or still needs checking, I've said so.

The screenshots are from the original setup. The terminal images show the original output with the surrounding viewer left out; the viewer may have scaled them. The physical setup photo and DNS image are the supplied originals.

I haven't rerun the migrations or done a new restore test just to write the documentation. In particular, the idle ATM10 heap sample doesn't tell me how it performs under load, and the Bedrock archive check doesn't replace a full restore.
