# Evidence and documentation conventions

This project is reconstructed from the owner's original setup conversation, including terminal transcripts, original image attachments, hardware assessments, migration results, and gameplay confirmation. Private chat links are not required to navigate the repository.

## How to read the evidence

| Evidence type | Meaning |
| --- | --- |
| Original screenshot | A reviewed image from setup, reproduced in the gallery |
| Recorded output excerpt | A selected portion of a terminal transcript; omissions are indicated |
| Historical command | A command used or proposed in the original workflow, with contextual explanation |
| Sanitized command | An original workflow with addresses or transient PIDs replaced by explicit placeholders |
| Reference sequence | A readable sequence assembled for this documentation; not represented as newly executed |
| Proposed improvement | Follow-up work without a claim of completion |

## Verification levels

Process state, a listening port, successful DNS resolution, a player's successful connection, readable backup contents, and a restored playable world are distinct outcomes. A result at one level is not presented as proof of every later level.

For example, the Bedrock archive listing confirms readability, while ATM10's idle heap capture describes one sample. Neither establishes a restore test or performance under multiplayer exploration.

## Screenshot handling

The DNS image is the original attachment. Terminal captures reproduce the original attachment in its viewer, with the surrounding interface excluded. Pixel dimensions may differ from the uploaded image because the viewer scaled it. The output has not been rewritten, generated, or retouched.

Images were inspected before publication. The selected evidence contains no credentials, public IP addresses, player identifiers, or machine/boot IDs. The DNS image includes the public hostname shown during setup.

## Scope of this repository work

The documentation and local links were checked before publishing. No live game server configuration was changed, no migration commands were rerun, and no new performance benchmark or backup restore was performed.
